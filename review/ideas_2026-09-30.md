## A. Ответы на вопросы раздела 9 брифа

### A1. Разнообразие смеси и стекинг (вопрос 1)

E130 доказал: резерв в **разнообразии**, не в признаках (корреляция 0,988–0,992, сам по себе не точнее,
в смеси −0,78 CV). Оси по убыванию отдачи, все — партнёры с весом по OOF (как E81/E100), мета-веса
**фиксированные по OOF, не переучиваются на full-моделях** (урок Паниграхи T24: веса по in-sample —
утечка; наш NNLS по OOF-фолдам строже):

1. **CatBoost на сыром y** (аналог E130, второе семейство). E130 — LightGBM; CatBoost-сырой не пробован,
   сиды уже считаются тем же кодом (`catboost_reg.py` с целью raw). Ночь на маке. Прогноз: −0,2…−0,5 CV.
2. **TabM (Apache-2.0)** — стоит в «отложено, не закрыто» с 16.09 (method_survey №7). MLP ошибается иначе,
   чем деревья; это третий-четвёртый член рядом с сетью E100. OOF 6 фолдов, вес NNLS по обучающим месяцам
   фолда. Прогноз: −0,2…−0,6 CV, перенос ~1/3–2/3 (E100: −0,66 CV → −0,26 LB).
3. **kNN-ретривал по «похожим вылетам 2025»** (ключ: аэропорт × ВПП × стоянка/префикс × час × тип × префикс
   оператора; веса по Махаланобису или обратному расстоянию). Прямо назван в нашем же вопросе 1; литературная
   опора — DDA-SIM-ATT (Aerospace 2026, разд. Г). Это НЕ E35/E60 (соседи как датчик для бестрековых строк,
   отклонены) и не бленд чужих строк — это партнёр-регрессор. Прогноз: −0,2…−0,5 CV.
4. **Гистограммная голова** (method_survey №2): LightGBM multiclass по ~64 квантильным бинам остатка,
   прогноз Σp_k·center_k — условное среднее без смещения под хвост. Косвенное подтверждение уже у нас:
   TabPFN-2 (распределение по бинам) — единственное, что поднял хвост LIRF. Прогноз: 0…−0,3.

Стекинг уровня 2 без утечки при наших фолдах (пара месяцев k, k+6): OOF-прогнозы членов уже есть
(`cv_preds*`, `cv_preds_e116prod`), члены на ranking обучаются на всех 12 месяцах — мета-веса брать
только фиксированные из OOF (выпуклый NNLS/Грам), никогда не переучивать на full-моделях и никогда
не выбирать вес по доске (урок №33: бленд по доске существует только при подгонке весов).

**Б2.** Форма: монотонная (сохраняющая ранг) переплавка финального выхода внутри групп «аэропорт ×
(есть/нет NM) × месяц» к эмпирическим квантилям OOF-2025 тех же групп. Ничего не учит на 2025 повторно —
чистый тип (1), единственный класс, переносившийся с усилением (E46: −0,40 CV → −1,00 LB). Гейт: обучение
переплавки на 5 фолдах OOF, применение на 6-м, усечённые < 0 и ниже в ≥4/6; на доску — только группы
«обычные строки» (max P планового режима < 0,95), хвост не трогать (у него свои кандидаты). Сначала
замер-потолок: сравнить эмпирические квантили OOF vs 2026-выходов по аэропортам — если совпадают, дальше
не стартовать. Риски честно: E50 (+5,78, но это классификатор/признаки), E55 (+0,46, изотоника прокси,
не выхода), E145 (+0,114, сдвиг к внешним PRU-агрегатам). Отличие: переплавка не добавляет информации,
только чинит систематику квантилей; монотонность сохраняет качество внутри групп.

**Б4.** Физика: если трек начинается после записи отхода, то y = MVT − BLOCK > MVT − t_move ≥ 0, т.е.

не трогать (E152). Проверка на OOF: доля строк, где пол активен, и доля, где истина ниже пола (должно
быть ≈0).

## Д. Процесс к финалу (по Canedo-заметке, переносимо)

1. **Мутационное тестирование ворот:** до заморозки скормить гейту 4–5 заведомо испорченных кандидатов
   (+60 с на 5 % строк; перестановка внутри суток; утечный OOF; дубли строк; сдвиг одного аэропорта).
   Гейт, «зеленеющий» на мутанте, не различает класс ошибок — снять/поправить. Часы работы, ноль счёта.
2. **Паспорт версии у каждого кэша** (хэш входов + конфиг + коммит, отказ при несовпадении) — класс ошибок
   E151/E133 (ничьи в сортировке, недетерминированность) закрылся бы механически.
3. **Парный sign-flip тест по аэропорто-суткам** для прибавок <0,3 с (бутстрэп по суткам, не по строкам —
   строки внутри суток коррелированы).
4. **Печатать n рядом с каждой метрикой** (голодный прогон имитирует точный — 2609.00243).
