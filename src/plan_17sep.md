# Очередь сабмитов 17.09 (5 слотов, сброс 00:05 UTC)

| Слот | Версия | Что проверяет | Сравнение |
|---|---|---|---|
| 1 | v45 = v26 + этап E42 (геометрия стоянки по аэропортам) | лучше ли E42, чем E36 | против v30 = 252,43 |
| 2 | v50 = финал на признаках E32 + этап E36 (E47) | переоткрытый E32 по исправленной метрике | против v30 |
| 3 | v51 = финал E32 + лучший этап из слотов 1–2 | складываются ли два улучшения | против лучшего из слотов 1–2 |
| 4 | по итогам E46 (коэффициент доверия расписанию), если принят | | против лучшего |
| 5 | резерв: повтор лучшего варианта с другим сидом или откат | | |

Слоты 3–5 назначаются после того, как придут оценки слотов 1–2 (обычно за минуты).

**Очередь запущена только с v45** (`nohup ./src/submit_17sep.sh 45`). Когда сборка E47 напишет v50, очередь нужно
перезапустить с обеими версиями: убить старый процесс `submit_17sep.sh` и запустить `./src/submit_17sep.sh 45 50`.
Скрипт сам ждёт 00:05 UTC и считает лимит по своему логу.
