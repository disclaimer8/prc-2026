# Row-level outputs kept out of the repository

Two outputs of this analysis list individual 2025 departures by challenge movement ID
together with challenge timestamps or quantities derived from the recorded block time:

| File | Rows | Content | SHA-256 |
|---|---:|---|---|
| `raw_episode_audit.csv` | 15,758 | ID, day, airport, month, delay bin, NM presence, admission result, first near-stand time, its difference from the recorded block time | `790d8733ca408e7a72abce537f4c42ade43331e7b04ecbd7363c42754e23f219` |
| `posthoc_admission_rows.csv` | 7,870 | ID, day, airport, admission gates, first raw point time, take-off time, stand distance, speed | `68643260b19e2e46e984fad9a952cf64ab1b4f3fea1f2668c6928e823b5772c9` |

Together they let a reader reconstruct recorded taxi-out labels for these flights. The
challenge data are not redistributed under this repository's licence (see `SOURCES.md` and
the README), so both files stay out of Git and are listed in `.gitignore`. They are
regenerated by `scripts/planning_copy_triangulation_20261012.py` and
`posthoc_admission_diagnostic.py` in this directory from the challenge files; the hashes
above match `results.json`, `verification.json` and `FINAL_REPORT_HASHES.json`, and the
files are available to the organisers on request. All aggregate outputs (`alignment*.csv`,
`availability.csv`, `stand_*`, `raw_attrition.csv`, `raw_day_inventory.csv`, JSON results)
remain in the repository.
