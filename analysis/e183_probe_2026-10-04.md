# E183, проба: «состояние соседей» по остатку нашей модели (04.10.2026)

Идея №1 из обхода конкурентов (`analysis/competitor_repos/_UPDATE_2026-10-04.md`, разд. (c); smart-jigsaw §70–72,
`tests/neighbour_state_v2_test.py`). Проба без обучения: несёт ли бесметочный ADS-B-прокси остатка соседей информацию
об остатке строки **без собственного трека**.

## Правило остановки (записано 04.10 ~16:58Z, до первого прогона)

**Определения (зафиксированы до счёта):**
- **s** — боевой OOF базы FIN1b (`data/cv_preds_fin1b_hz/fold_*.npz`, поле `pred`), остаток `r = y − s`.
- **Строка без своего трека** — `coverage < 2` по боевой выгрузке `data/adsblol_kt1/offblock2_2025-*.parquet`
  (так этап E141 отбирает свои строки: `coverage ≥ 2`). Подмножество «без ADS-B вовсе» — ещё и не цель этапа E64
  (`vi_has_prev ≠ 1` в `data/adsblol/visit_2025-*`); считается рядом, отчётно.
- **nbq_j** (соседи с наблюдённым отходом, `coverage == 3` в kt1) = `clip((MVT − t_first_move)_j + лаг_аэропорта − s_j, ±1800)`;
  лаг = медиана `y − (MVT − t_first_move)` по строкам `coverage == 3`, 0 < y ≤ 7200, по аэропорту (константа, в
  центрированной версии сокращается).
- **nbp_j** (NM-прокси) = `(MVT − AOBT_3)_j − s_j`, где `MVT − AOBT_3 ∈ [1, 5399]`.
- **Оракул** = средний настоящий остаток соседей `r_j` (только y_j ≤ 7200).
- Средние по окнам ±15/30/60 мин по `MVT_TIME`, по аэропорту и по (аэропорт, ВПП), без себя, ≥ 2 соседа с определённой
  величиной.
- Целевые строки: без своего трека, 0 < y ≤ 7200, AOBT_3 не требуется.
- **Центрированная** корреляция: и признак, и `r` минус их средние по (аэропорт, UTC-сутки) среди целевых строк с
  определённым признаком.

**Решающее число:** центрированная corr(r, nbq) в окне **±30 мин по аэропорту** на целевых строках.
- **Шаг 2 (идём),** если |corr| ≥ 0,10 хотя бы в **3 аэропортах** с заметной долей строк без трека (≥ 10 % вылетов
  аэропорта в 2025 и ≥ 2 000 целевых строк с определённым nbq) **и** знак объединённой по аэропортам центрированной
  корреляции одинаков в **≥ 9 из 12 месяцев**.
- **Стоп, идея закрыта пробой,** если |corr| < 0,05 во всех аэропортах.
- **Серая зона** (между): шаг 2 сам не начинаю; отчёт с числами, решение за вызывающим. Варианты окна (±15/60, по ВПП)
  и порог 0,10 на них не переносятся — они отчётные.

## Вывод

1. **ADS-B-прокси nbq у нас стоит ноль** (+0,002 с, 3/6). Корреляция есть (0,08–0,13 в пяти аэропортах), но популяции не
   пересекаются. 92 % строк без трека — LTFM, LFPG, EGLL, LIRF, LEMD; там у соседей тоже нет трека (nbq есть у 0–18 %
   строк). Там, где nbq есть (EDDF, EDDM, EHAM, LEBL, LSZH), строк без трека в 2025 — 65 тыс. (8 %). В ranking та же
   картина: из ~121 тыс. строк без трека 95 тыс. — LTFM, LFPG и LIRF, где nbq ≈ 0. Новое только одно: в EDDF доля без
   трека выросла до 25 % (9,2 тыс.), но nbq там есть лишь у 12 %.
2. **Общая во времени ошибка у нас есть** (оракул 0,20–0,34, линейно −3,8 с), но бесметочными прокси она не
   достаётся.
3. **NM-прокси nbp** даёт в парах месяцев −0,16 (6/6), но **не переносится вперёд по времени.** Обучение на январе–июне →
   июль–декабрь: +0,055; LTFM в полугодиях +0,021 против −0,086 в парах. Это то же «старение соседских связей», которое
   smart-jigsaw видел на доске (перенос ≈ половина). У нас база уже держит 64 признака соседей (nb_/nbf_/nbs_/fw_), так что
   остаётся сигнал соседних месяцев. Ожидание на доске — ≈ 0 или хуже. Подробнее — разд. 21f брифа и E35/E60.
