Все четыре arms находятся локально в `data/e197_trajectory_20261007` (~195MiB). Большие prepared tables (~19GiB) на Mac не переносились; их исходный Home evaluator проверил на месте. Support-подгруппы сохранены из исходного authenticated evaluation, локально без этих таблиц не пересчитывались.

Полезный сигнал установлен для LGB5/pre-ADSB component screen. Это не проверка current full chain, не независимая fully nested CV и не измерение leaderboard. Отрицательный E192 по соседним событиям не отменял этот другой механизм: E197 использует порядок реальных точек собственного борта в двух визитах. Результат поддерживает зарегистрированное подтверждение E202; production требует своей полной проверки.
