# Задание для Gemini Deep Research (15.09.2026)

## Роль и цель

Ты — исследователь по аэропортовым операциям, ADS-B и табличному машинному обучению. Нужно найти **новые, проверяемые рычаги**, которые снизят RMSE прогноза taxi-out ещё на ~12 с (с 258 до ≤ 246) в соревновании EUROCONTROL PRC Data Challenge 2026. Ищи в англоязычных источниках (статьи, репозитории, документация данных, форумы ADS-B), отвечай по-русски.

## Задача соревнования

- Прогноз taxi-out вылета в секундах: `MVT_TIME` (взлёт) − `BLOCK_TIME` (off-block), 10 аэропортов: EDDF, EDDM, EGLL, EHAM, LEBL, LEMD, LFPG, LIRF, LSZH, LTFM.
- Обучение: все движения 2025 года (4,17 млн строк, 2,09 млн вылетов). Данные аэропорта (стоянка, ВПП, тип ВС, расписание, block time прилётов) склеены с данными EUROCONTROL Network Manager: IOBT, EOBT, LOBT, AOBT (оценка NM), ARVT, сегмент рынка; оператор анонимизирован.
- Тест: январь и июль 2026, 344 841 вылет. Скрыты только BLOCK_TIME и taxi-out вылетов; время взлёта, NM-времена и все прилёты видны.
- Метрика: RMSE по всем вылетам. Лимит 5 сабмитов в день, дедлайн 11.10.2026.
- **Правила приза:** только открытые внешние данные с документированной лицензией; код открыт под GPLv3; решение оригинальное. Запрещены: OpenSky Trino, прощупывание лидерборда, платные/закрытые данные (FR24, FlightAware, A-CDM, платные NOTAM), некоммерческие лицензии.

## Что известно о данных

- Метрику двигают редкие строки: у части вылетов BLOCK записан как плановое время (SCHED), IOBT/LOBT/EOBT или со сдвигом на сутки — таргет до 90 000 с. Основной хвост — LIRF без записи NM.
- |BLOCK − LOBT| ≤ 3606 с на всех строках с LOBT (окно сопоставления NM).
- У 1,6% вылетов нет записи NM, они дают ~2/3 суммы квадратов ошибок валидации.
- Конфигурации ВПП в 2026 сдвинуты относительно 2025.

## Текущее решение (лидерборд 258,18, 5-е место; топ-3: 245,02 · 245,29 · 246,48)

1. Смесь режимов: многоклассовый LightGBM (обычное руление / SCHED / IOBT / LOBT / EOBT / +сутки); прогноз = Σ p·кандидат; маска и клип по окну LOBT.
2. Для LIRF без NM при задержке 4–30 ч вероятности режимов из TabPFN-2; для задержки < 4 ч — логит по истории номера рейса.
3. Регрессор обычного руления — остаток от калиброванной цепочки AOBT → LOBT → EOBT: 0,65 CatBoost + 0,35 LightGBM (5 сидов). Признаки: загрузка аэропорта и ВПП, соседние вылеты (взлёт − AOBT) в окнах до и после своего взлёта, прилёты на стоянку и ВПП, OSM-геометрия стоянка → ВПП, METAR, OOF target encoding.
4. **Второй этап по наземным ADS-B-трекам adsb.lol globe_history (ODbL)**: трек сопоставляется по позывному; признаки — первая наземная точка, первое движение после стоянки, конец последней остановки, длина пути, остановки; LightGBM на остатке. Дал −15,2 с на лидерборде. Покрытие вылетов треком: EHAM/LEBL/LSZH/EDDM ~95%, EGLL ~90%, LEMD ~80%, LFPG ~23%, LIRF ~36%, LTFM 0%.

## Что уже проверено и НЕ помогло (не предлагать без нового механизма)

- Отдельная модель для строк без NM; признаки «дня-сбоя»; множитель в дни снегопада (EHAM 2–7.01.2026 — истина ~2500 с, не 5000).
- Идентичность рейса из самого теста (регулярность номера), местные римские сутки, «порядок записей» MVT_ID/FLIGHT_ID, признаки ARVT_3.
- Выбор раундов классификатора по SSE смеси; асимметричный лосс; модели выживаемости; Isolation Forest для выбросов; pseudo-labeling; GNN по графу аэропорта.
- P10/P50 по стоянке×ВПП, ветер на ВПП, NOTAM.
- ACARS/VDL2 adsb.lol (у LIRF нет OOOI-сообщений; январь 2026 почти пуст); события OPDI (off-block есть только у LSZH; лицензия некоммерческая).
- ADS-B: сопоставление по времени взлёта без позывного (13% неверных бортов); расширение поправки до ±2 ч.
- Сейчас проверяются: признаки ADS-B внутри основной модели; ADS-B-время руления соседей для рейсов без своего трека; геометрия стоянки в треке (первое движение ≤ 150 м от своей стоянки — медианная ошибка к BLOCK 68 с против 473 с).

## Что нужно найти

1. **Открытые источники фактического off-block / pushback / taxi-start** для этих 10 аэропортов за январь и июль 2026 (и 2025 для обучения), особенно для **LFPG, LIRF, LTFM** и для строк без NM. Для каждого: URL, формат, покрытие по аэропортам и датам, лицензия (подходит ли для коммерческого приза), объём, как скачать. Примеры направлений: другие ADS-B-агрегаторы с открытой историей (MLAT, наземные приёмники у аэропортов), открытые данные аэропортов/ANSP, A-CDM-публикации, Mode-S EHS, спутниковые снимки стоянок, публичные табло вылетов с фактическим off-block (архивы Wayback), открытые наборы исследований.
2. **Как по наземному ADS-B надёжно восстановить момент off-block** (pushback, буксировка, запуск двигателей, неполные треки без начала). Методы и открытый код из литературы: сегментация фаз руления, скрытые марковские модели, сопоставление со стоянками OSM/AIXM, работа с «обрезанным» началом трека, MLAT на земле.
3. **Механизм записи BLOCK в AODB** крупных европейских аэропортов: когда в поле пишется плановое время или время со сдвигом на сутки, как это связано с A-CDM (TOBT/TSAT/AOBT), что известно про LIRF (Фьюмичино) и аэропорты без A-CDM. Любые признаки из видимых полей, которые это предсказывают.
4. **Методы прошлых PRC Data Challenge (2024, 2025) и смежных соревнований** (прогноз taxi-out, off-block, TOW/ETA) — приёмы, которые дали крупный выигрыш и которых нет в списке выше.
5. **Табличные методы для смеси редких дискретных режимов** под квадратичную ошибку, если есть результаты лучше «многоклассовый GBDT + TabPFN на хвосте».
