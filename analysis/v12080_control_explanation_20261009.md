## 1. Инструмент и его проверка

(хвост разобран отдельно, §4). Контроли:

- старый премикс (clf_v870 + старый FIN1b + cat_fin1b_seeds15 / lgb_reg_seeds_v870 / e130_* / 10-сидовый NN) из

Разложение замыкается: 0,959 + 0,036 + 0,004 = 0,999 от ‖F − H‖². Нелинейность смеси даёт взаимодействие
(RMS 5,6 с: сумма одиночных замен 20,38 против совместной 19,70). Жёсткая граница |Δs| ≤ RMS(Δ_k) ни одного
источника не исключает (у всех RMS > 0,56 с); исключает масштаб шума: члены (σ 10–15 с²), продукты, дизеринг
кандидатов и motion не могут дать −260 с² без 17–170σ, хвост — без 6σ. Носитель — вероятности режимов.

**Члены — без признаков подмены.** На янв/июл финальные семейства отличаются от членов v12075-эпохи на RMS 19–21 с
(NN 29 с), сидовый разброс одинаков (Cat 32,6/32,6 с, LGB 25,2/25,1, якоря 25–28, motion 29,7/29,7); ожидаемый
шум разности средних 12–18 с (NN 23 с), систематическая часть 11–15 с (NN 18 с) — пересчитанные входы (дизеринг MVT
и всё производное, медианы plan_* по четырём месяцам, нормировки NN final-view); средние сдвиги +0,33…+0,55 с.
Одноимённые сиды старого и нового рефита различаются как независимые (34–43 с).

**Классификатор: что именно поменялось.** Параметры двух моделей совпадают (кроме `num_threads` 10 → 6), 1 080 деревьев,
те же 170 признаков, те же 2 085 047 обучающих строк. На строках 2025 из 170 признаков классификатора по значениям
отличаются только `plan_taxi_res` и `plan_nm_taxi` (94 % / 88 % строк, средний |Δ| 21–22 с, p99 120–147 с: медианы E165
по маршруту берутся по «2025 + ранжированию» — по построению без меток, теперь по четырём месяцам) и пограничные
`stand_next_arr_gap`/`rwy_to_next_arr`/`fw_*` (≤ 776 строк); категориальные признаки совпадают все. Матрица 2×2 на
янв/июл: смена модели — средний TV вероятностей 0,0069 (p99 0,052; LIRF без NM 0,027, без направления: ΔP(sched)
−0,0008), смена входов — 0,0024 (p99 0,022; LIRF без NM 0,019, ΔP(sched) −0,010). Т. е. это обычная
пере-реализация модели плюс отклик на пере-дизеринговые входы, сосредоточенный там, где режим неопределён.

## 5. Масштаб шума и тождество Грама

- **Равновесная перетасовка шума** даёт E[ΔMSE] = 0 и corr(Δ, остаток) = −RMS/(2s) = −0,044; наблюдено −0,0715.
- **σ(ΔMSE) без меток.** Остаток строки ≈ дисперсия смеси режимов, откалиброванная по бинам на OOF янв+июл 2025
  (`cv_preds_e116prod/fold_1_7`): σ = **200 с²** (линейная калибровка — 251 с²) ⇒ z = −1,30 (−1,04). По линейной калибровке 98 % σ² даёт
  та же группа из 345 строк. Общие компоненты остатка по аэропорт-дню/часу (τ = 24 / 57 с по 2025) σ не меняют.
  Оговорка: на чистой паре v12076 − v12075 (вложенное снятие шума сидов, ожидаемое −23,5 с²) тот же прокси даёт
  z ≈ −5 — для размазанных изменений он занижает шум; но размазанная часть F − H (члены) по σ ≤ 15 с², и даже
  ×5 итог ≈ 220 с².
- **LIRF без NM (341 строка вне хвоста, 44,8 % Σ²)** в двухточечной модели меток (y ≈ regular или ≈ sched): если
  верна калибровка H, ΔMSE группы = **+155 с²**; если верна калибровка F — **−181 с²**; если все строки regular —
  −872, если все sched — +709. Биномиальная σ группы — 190 с². Средние P(sched): 0,420 (H) и 0,409 (F). Чтобы одна
  эта группа дала −260 с², реальная доля sched должна быть на 26 п. п. ниже прогноза H; помесячный разброс
  калибровки этой доли в 2025 — sd ≈ 0,07 (от −0,08 до +0,14; июль 2025 −0,08). Значит, −260 с² — это лотерея всей совокупности режимных
  строк, а не одной группы; сама группа даёт до ±400 с² на 2σ.
- **Грам по известным оценкам** ([gram.json](v12080_control_explanation_20261009/results/gram.json)): середина (F + H)/2
  = √((231,1805² + 231,7429²)/2 − 20,358²/4) = **231,238** — хуже F: выигрыш F — это конкретная реализация,
  а не меньший шум. H против канарейки v12090 (RMS 10,4 с): −0,450 с — эффект 10 сидов + весов без E81 равен
  измеренному с E81 (−0,4575, №427), аддитивность цепочки держится. v12079 и v12080 при RMS разности 25,3 с оценены почти одинаково (231,1770 и 231,1805).

## 6. Вывод для финала и документации

1. **Проблемы нет.** Члены — заявленные (премикс воспроизводится точно, ID выравниваются по `MVT_ID_mvt`, сидовый
   разброс тот же); утечки нет (DEP `BLOCK`/`TAXITIME` в final_ranking — null, адаптер табличных фитов это проверяет,
   обучающие ID те же 2 085 047; единственные отличия обучающих признаков — безметочные медианы plan_*);
   стадии обслуживают те же строки; кешированные модели те же.
2. **Механизм:** пере-реализация вероятностей режимов (рефит классификатора + входы финального файла) на ~350 строках
   со смесью далёких кандидатов; на этот раз в пользу (≈ 1–1,3σ). Для слепых месяцев та же лотерея с тем же знаком
   не гарантирована; менять нечего.
3. **Урок для коридоров:** для цепочки с переобученными членами шум контроля ≈ ±0,45–0,55 с (1σ), а не ±0,3; и
   оценка дизеринга ±0,08 с (jitter-анализ) не покрывает отклик переобученного классификатора на новые входы
   (только «вид» здесь — σ ≈ 134 с² ≈ 0,29 с).
4. Правило И7 выполнено: расхождение объяснено постадийно; решение о финальном PUT — за координатором.

**Не проверялось:** поштучные исходы режимов (нужны метки); корреляция режимных остатков внутри LIRF-дня (расширила бы
σ); разделение «вида» на дизеринг MVT, медианы plan_* и соседей фев/июн — для этого нужен рефит классификатора
на старом виде, фитов в этой работе не было.
