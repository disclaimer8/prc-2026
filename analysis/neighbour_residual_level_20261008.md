## 2. Определения (зафиксированы до прогона, докстринг скрипта)

Все величины наблюдаемы в момент прогноза и считаются одинаково на OOF 2025 и на входах 2026: метка самой строки и метки любых
вылетов не используются.

- **S1** `nbp_apt`: вылеты j ≠ i того же аэропорта, `v_j = clip((MVT − AOBT_3)_j − s_j, ±1800)` при `(MVT − AOBT_3) ∈ [1, 5399]`;
  вес `exp(−|t_i − t_j| / 1800 с)` (α = 0,717 за 10 мин), окно ±60 мин по MVT_TIME, ≥ 2 соседей, без себя; `s_j` — тот же прогноз
  цепочки, который правим.
- **S2** `arrx`: прилёты того же аэропорта, `v_j = clip(taxi_in_j − норма, ±1800)`, норма — медиана по (ADES, ВПП, стоянка ≥ 20) →
  (ADES, ВПП) → ADES из других месяцев 2025 (как U1); то же ядро по времени посадки. Taxi-in прилётов есть и в ranking.
- **S3** `nbp_rwy`: S1 внутри той же (аэропорт, ВПП).
- Каждый S центрирован по (аэропорт, UTC-сутки) среди определённых строк; неопределённый → 0. Определены на 99,9 / 100 / 99,5 % строк.
- **β** — МНК без свободного члена остатка `y − pred` на (S1, S2, S3) **по аэропорту**, только на 10 обучающих месяцах фолда,
  строки `evaluation_mask`, 0 < y ≤ 7200, pred ≤ 7200. Применение: строки пары с pred ≤ 7200, кроме LIRF без NM; округление.
- Метрика: парный квадрат ошибки против неизменённой цепочки; LB-секунды = Σ/(6·2·252,43·344 841).
- **Гейт** (основное плечо joint, S1+S2+S3, β по аэропорту): decided ниже в ≥ 4/6; пул decided < 0; пул trim20 < 0; тело < 0;
  2+8 и 6+12 ≤ 0. Отчётно: плечи по одному сигналу, глобальный β, полугодия вперёд/назад, то же на OOF базы FIN1b.
- **Прогноз до прогона:** пул −0,05…−0,20, 4–5/6; полугодие вперёд слабее или в плюс. Сбылся по всем трём пунктам.

### 3.1. Где выигрыш: один аэропорт, один месяц

Пул decided по аэропортам (основное плечо): **LTFM −0,060**, LFPG −0,025, EGLL −0,012, EHAM −0,004, остальные |·| ≤ 0,002.
В решающем фолде 2+8 (−0,059) LTFM даёт −0,055. Центрированная corr(остаток, S1) в LTFM по месяцам: **февраль −0,250**
(S3 −0,272), остальные −0,10…+0,02; по всем аэропортам февраль −0,135, другие месяцы −0,00…−0,04.

Механизм в LTFM — не «состояние аэродрома», а **вырожденный прокси AOBT_3** (бриф, разд. 7 п. 7): медиана `MVT − AOBT_3` в LTFM
скачет режимами 1434 с (янв–мар, ноя) ↔ 1198–1203 с (апр–окт, дек), и в феврале связь «прокси соседей − прогноз» с остатком
резко сильнее. β по месяцам в LTFM меняет знак (S1: −0,06, −0,11, +0,03, +0,10, −0,01, +0,02, −0,06, −0,01, −0,12, −0,06, +0,07,
+0,05) — это не устойчивая связь, а помесячный узор ошибки источника. Знаки β по аэропортам тоже разные (S1: LSZH +0,04,
LEMD +0,02 против LFPG −0,04, LIRF −0,09, LTFM −0,03), что согласуется с P4b отчёта C: «состояние» — во многом общая во времени
ошибка NM-часов, своя у каждого источника.

## 4. Вердикт

- **Гейт №399 пройден формально, предзаявленное красное плечо — красное.** Коррекция уровня по безметочному остатку соседей
  на нашей цепочке в финал **не рекомендуется**: ожидание на фев/июн 2026 по честным плечам «вперёд» **+0,04…+0,16 с**, а не −0,10.
- Общая во времени ошибка существует (оракул P4 0,2–0,38), но безметочные прокси её не достают — третий раз (E183 nbq/nbp, U1, E211).
  Направление «состояние соседей по остатку» закрыто и для всех строк, не только бестрековых.
- Что было бы нужно, чтобы вернуться: сигнал, устойчивый при обучении ≤ k−2 → k (0/9 здесь), или прямое наблюдение остатка
  соседей без прокси AOBT_3 (у нас его нет: ADS-B-соседи живут в других аэропортах, E183).
