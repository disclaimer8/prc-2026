## 4. Правило защиты R2 (№397): пред-регистрация → оценка → вердикт

Правило: на строках без токенов и без visit `reg' = (reg − c·nn)/(1 − c)` (c = 0,25 или 0,25·23/30 на E185-строках), остальное без изменений.
Контроль — OOF premix с NN (`prediction.npz: pred`, воспроизведён из `control.npz` + member побитно на 6/6 фолдах), кандидат — тот же `assemble`
с `reg'`. Популяция: evaluation_mask ∧ без токенов ∧ без visit = 417 194 строки.
