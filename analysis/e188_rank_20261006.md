# E188: фиксированный ranking-протокол 06.10.2026

Пользователь разрешил полные ranking-подачи до 00UTC без ожидания полного
current-chain CV. Это разрешение не превращает stage-screen в полную валидацию.
Сохраняются обязательные проверки полного состава ID, конечных значений,
неизменности остальных строк и 42 доноров TabPFN на выходе полного хвоста.

Код: `scripts/e188_rank_20261006.py`. Новый fit строго после регистрации кода
и протокола одним коммитом; fit проверяет собственное содержимое в этом коммите.
Общие исходники, активные очереди и прежние артефакты не изменяются.

Фиксированный fit: прежний training-parent `cv_preds_nomonth`, готовый bundle
`data/visit_mask_inputs_20261005_v2` и прошедшее parity извлечение
`data/visit_mask_20261005_v2` (регистрация
`da89a73846aa675d591ba5121bd2391241652a80`). Все natural E64-строки 2025:
coverage < 2 и vi_has_prev = 1; keep-all; residual clip [-1800,1800].
Добавляются все 60 327 train-only synthetic LIRF/NM из зарегистрированной
проверки stable ICAO/previous visit/изменённого действующего признака,
coverage=1, вес=0.25. Natural-вес=1. D3 удаляет vi_n_pts/vi_prev_pts/vi_alt_first.
Сохраняются 400 rounds, seeds [42,1,2,3,4], параметры исходного screen;
только num_threads=4 вместо 6 для ресурса Mac. Никакого выбора сидов или веса.

Ranking: только настоящие coverage/visit из 2026, без synthetic-преобразования.
Признак base берётся из входа E64 (для прежней цепочки v12043), p_nonreg из
соответствующего parts (v12041). Предсказания усредняются по всем пяти моделям,
прибавляются к base, ограничиваются снизу нулём и округляются как e64_apply.py.
Замена применяется только на LIRF с NM, coverage<2, vi_has_prev=1; остальные
строки берутся точно из полного обычного E64-выхода (прежний v12044).

Контракт артефактов:

- `data/e188_rank_20261006/`: пять моделей, fit_started.json и завершающий
  fit_manifest.json; без final manifest модельный комплект не готов.
- Apply создаёт полный stage parquet из 344 841 строки и JSON receipt.
  Это вход оставшегося хвоста, не готовый финальный сабмит.
- Для комбинации с E190 повторный fit не нужен: apply принимает её новые
  pre-E64/post-E64/parts и вычисляет residual на её действующем base.

Обязательный хвост после apply: E152 gate=.95 с соответствующим pre-stage
TabPFN-файлом → E81 (base .8516, v44 .1214, v60 .0270; штатное округление)
→ LOBT edge lift/clip → восстановить 42 исходных значения TabPFN v361.
Для полного родителя сохраняется E159 LSZH half-blend. В E188-only LSZH и все
нецелевые аэропорты должны совпасть с v12061; можно перенести только уже
полностью обработанные целевые LIRF-строки на v12061, проверив базовый хвост.
Для E190-комбинации нужен её собственный полный хвост и LSZH шаг.

Measured evidence: screen natural LIRF/NM ΔRMSE=-0.606867 с, 4/6; synthetic
-2.772305 с, 6/6; обе body/trim ноги отрицательны. Это не прогноз доски.
Ранее рассчитанный масштаб natural screen на полный training:
ΔMSE=-6.867, примерно -0.0137 с при RMSE250, без гарантии переноса.
Полноцепочечного CV и измеренного ranking-score E188 пока нет.

